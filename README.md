# dannydeleon.com — artist site

Static site on GitHub Pages (CNAME dannydeleon.com). Text lives in data/site.json (bio, stats, selected sets, links, photos).

Releases load live from https://dandelionmusica.com/data/releases.json (any release whose artists include "Danny Deleon"), so a release added to the label site appears here automatically. data/releases-fallback.json is a backup copy.

Photos: /photos (web-sized exports from Media Vault > Photo shoot). Meta pixel fires only on dannydeleon.com.
